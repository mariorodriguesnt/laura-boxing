# Laura Carriello · Boxe

Site mídia kit da boxeadora Laura Carriello. HTML, CSS e JS puros, sem build. As fontes ficam na pasta `fonts/`, sem depender do Google Fonts.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `laura-carriello`).
2. Envie **o conteúdo desta pasta** para a raiz do repositório, com o `index.html` na raiz.
3. No repositório, vá em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.
4. Em 1 ou 2 minutos o site fica no ar em `https://SEU-USUARIO.github.io/laura-carriello/`.

## Depois de publicar

Troque no `index.html` o `content="img/og.jpg"` pela URL completa
(`https://SEU-USUARIO.github.io/laura-carriello/img/og.jpg`). Assim a prévia com foto aparece quando o link for compartilhado no WhatsApp e no Instagram.

## Estrutura

- `index.html` — a página inteira
- `img/` — fotos, imagem de compartilhamento (`og.jpg`) e ícone
- `fonts/` — Big Shoulders Display, Archivo, IBM Plex Mono (licença SIL OFL)
- `favicon.svg` — ícone da aba
- `.nojekyll` — faz o GitHub Pages servir os arquivos como estão
